# 服装图像分类GUI系统

这是一个基于Streamlit构建的现代化GUI应用程序，整合了模型训练和图像分类功能。

## ✨ 新特性

- 🖥️ **现代化GUI界面**: 基于Streamlit平台的直观用户界面
- 🔄 **双面板设计**: 可切换的训练面板和分类面板
- 📊 **实时监控**: 集成终端输出和训练进度显示
- ⚙️ **参数控制**: 丰富的参数设置选项
- 📈 **可视化**: 训练过程可视化和统计图表
- 🚀 **一键启动**: 提供批处理脚本快速启动

## 🚀 快速开始

### 方法一：使用启动脚本（推荐）

**Windows系统:**
```bash
双击运行 "启动程序.bat"
```

**Linux/Mac系统:**
```bash
./启动程序.sh
```

### 方法二：手动启动

1. **安装依赖**
```bash
pip install -r requirements.txt
```

2. **启动应用**
```bash
streamlit run app.py
```

3. **打开浏览器**
访问 `http://localhost:8501` 开始使用

## 🎯 功能模块

### 1. 图像分类面板

**主要功能:**
- 批量图像自动分类
- 支持三类分类：主图、吊牌、细节
- 可调节置信度阈值
- 实时处理进度显示
- 自动统计分类结果

**参数设置:**
- 模型目录路径
- 输入图片目录
- 输出基础目录
- 图像尺寸 (256/384/448/512)
- 批处理大小 (8-64)
- 置信度阈值 (0.1-0.9)
- 是否删除原始文件

### 2. 模型训练面板

**主要功能:**
- EfficientNetB0模型训练
- 支持迁移学习和微调
- 三阶段训练策略
- 实时训练进度和指标显示
- 自动保存最佳模型

**参数设置:**
- 训练数据目录
- 预训练模型目录
- 模型保存目录
- 图像尺寸 (256/384/448/512)
- 批处理大小 (8-64)
- 学习率选择
- 验证集比例
- 各阶段训练轮数

**训练阶段:**
1. **阶段1**: 冻结基础模型，训练分类头
2. **阶段2**: 解冻部分层，进行精调
3. **阶段3**: 全网络精调，使用学习率调度

## 📝 使用说明

### 数据准备

**分类任务:**
1. 将待分类图片放入指定目录
2. 确保有可用的训练好的模型文件

**训练任务:**
1. 按类别组织训练数据:
```
筛选/
├── 主图/
│   ├── image1.jpg
│   ├── image2.jpg
├── 吊牌/
│   ├── image3.jpg
│   ├── image4.jpg
└── 细节/
    ├── image5.jpg
    └── image6.jpg
```

5. **监控进度**: 观察实时输出和进度显示

## 🐛 常见问题

**Q: 启动时出现依赖包错误**
A: 运行 `pip install -r requirements.txt` 安装所有依赖

**Q: 模型加载失败**
A: 检查模型文件路径是否正确，确保文件完整

**Q: 训练过程中内存不足**
A: 减小批处理大小(batch_size)参数

**Q: 图像分类精度不高**
A: 尝试调整置信度阈值或重新训练模型
